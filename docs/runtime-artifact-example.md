The following example is based on a full Enterprise **trace-level runtime artifact** generated by WAIL during an AI execution.

This example represents an **N+1 runtime reroute execution**. A critical runtime degradation detected during the preceding request produced a reroute decision, which WAIL applied to this execution according to the active runtime policy.

Some execution-specific and cryptographic values have been abbreviated for readability.

## Notes

- This is a trace-level full Enterprise runtime artifact.
- Some execution-specific and cryptographic values are abbreviated for readability.
- The artifact represents an N+1 reroute applied from a decision produced by the preceding execution.
- `execution_target` preserves the source and target execution paths associated with the intervention.
- `routing_hysteresis` preserves the routing-stability evaluation associated with the reroute.
- `prompt_hash` is a cryptographic hash used for execution evidence; the raw prompt is not stored as part of runtime evidence.
- Runtime measurements, identifiers, hashes, fingerprints, signatures, and scores are execution-specific.
- Available sections depend on artifact type, enabled capabilities, and execution outcome.
- Agent Run evidence is a separate run-level artifact and is not represented by this trace example. See `examples/multi_agent_mcp_evidence.py` and `examples/multi_agent_runtime_recovery_evidence.py`.
- For field definitions, see the [Artifact Reference](artifact-reference.md).
